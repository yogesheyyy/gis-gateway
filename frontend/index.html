IMD Gridded Data

Official India Meteorological Department (IMD Pune) high-spatial-resolution daily gridded rainfall (1901–present) and temperature (1951–present) binary and NetCDF archives over India.

Temporal Range Daily (1901–Present)
Parameters Rainfall, Tmin, Tmax
Spatial Resolution 0.25° & 1.0° Grid
Source Agency IMD Pune (CRS)

30m GLO-30 GeoTIFF

Copernicus Global DEM

portal.opentopography.org

High-precision 30-meter Digital Surface Model (DSM) derived from the TanDEM-X radar mission for terrain relief, slope, and hydrological modeling without login requirements.

Spatial Resolution 30 Meters (1 arc-sec)
File Format GeoTIFF Raster
Coverage Global Surface
Provider ESA / OpenTopography
Visit OpenTopography Portal
5m+ Open IRS / SAR

ISRO Bhoonidhi EO Hub

bhoonidhi.nrsc.gov.in

NRSC/ISRO Earth Observation data hub offering free open access to Indian Remote Sensing (Resourcesat LISS-III/IV, EOS-04 SAR, Oceansat, CartoDEM) and NISAR S-SAR collections.

Spatial Resolution 5m to 56m (Open Policy)
File Format GeoTIFF / HDF5
Archive Span 1986–Present
Source Agency NRSC / ISRO
Visit ISRO Bhoonidhi
INSAT-3DR / 3DS HDF5

ISRO MOSDAC Archive

mosdac.gov.in

Meteorological & Oceanographic Satellite Data Archival Centre by Space Applications Centre (ISRO) for half-hourly INSAT cloud imagery, Hydro-Estimator rainfall, and ocean products.

Temporal Range 15/30-Min & Daily
Parameters Rainfall, OLR, SST, Winds
Coverage India & Indian Ocean
Source Agency SAC / ISRO
Visit MOSDAC Portal
0.25° Hourly NetCDF / GRIB

ECMWF ERA5 Reanalysis

cds.climate.copernicus.eu

Fifth-generation ECMWF global atmospheric, land-surface, and wave reanalysis providing hourly single-level and pressure-level climate variables from 1940 to the present.

Temporal Range Hourly (1940–Present)
Spatial Resolution 0.25° × 0.25° (~31 km)
Parameters 2m Temp, Wind, CAPE, Rad
Access Method Web UI & Python cdsapi
Visit Copernicus CDS
0.05° (~5.5 km) GeoTIFF / NC

CHIRPS Global Rainfall

data.chc.ucsb.edu/products/CHIRPS-2.0

Climate Hazards Center InfraRed Precipitation with Station data (UCSB). Direct HTTP directory download (no login required) for high-resolution daily and monthly rainfall grids.

Temporal Range Daily / Monthly (1981+)
Spatial Resolution 0.05° × 0.05° Quasi-Global
File Format GeoTIFF & NetCDF
Provider UCSB CHC / USGS
Open Direct HTTP Directory
Sentinel 1 / 2 / 3 / 5P

Copernicus Data Space

browser.dataspace.copernicus.eu

European Space Agency's interactive browser for instant visualization and raw product download of Sentinel-1 SAR, Sentinel-2 10m optical, and Sentinel-5P atmospheric trace gases.

Spatial Resolution 10m (S2) to 3.5km (S5P)
Sensors SAR, MSI, OLCI, TROPOMI
File Format SAFE / NetCDF / GeoTIFF
Provider ESA / EU Copernicus
Launch Copernicus Browser
0.1° GPM IMERG & MERRA-2

NASA GES DISC Archive

disc.gsfc.nasa.gov

Goddard Earth Sciences Data and Information Services Center hosting GPM IMERG half-hourly precipitation, MERRA-2 aerosol/radiation reanalysis, and OMI atmospheric products.

Temporal Range 30-Min / Hourly / Monthly
Key Collections GPM IMERG, MERRA-2, AIRS
File Format NetCDF4 / HDF5
Source Agency NASA Goddard (Earthdata)
Visit NASA GES DISC

USGS EarthExplorer

earthexplorer.usgs.gov

Comprehensive global catalog of multi-decadal Landsat (1–9) Level-2 Surface Reflectance imagery, SRTM 30m digital elevation tiles, and hyperspectral earth observation data.

Spatial Resolution 15m Pan / 30m Multispectral
Archive Span 1972–Present (Landsat)
File Format Cloud-Optimized GeoTIFF
Source Agency USGS EROS Center
Visit USGS EarthExplorer

HydroSHEDS & HydroBASINS

Direct open downloads (no registration required) for global hydrologically conditioned DEMs, flow direction/accumulation grids, watershed polygons (HydroBASINS), and river networks.
